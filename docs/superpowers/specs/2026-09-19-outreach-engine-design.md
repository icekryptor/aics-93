# Движок холодного аутрича: разбор → КП

2026-09-19 · спека · проект `aistov-space` (AICS-93)

## Задача

Двухступенчатый движок для холодного аутрича по владельцам сайтов.
Коммуникация — личная, её ведёт Василий. Движок отвечает только за два
артефакта: **разбор** сайта (первое касание, по нему человек открывает
ссылку) и **КП** (после живого разговора, по его фактическим цифрам).

Образцы качества, на которые равняемся: `public/kp/cooleso.html` — разбор,
`src/lib/kp/{broker,gagarin,bigsnt}.ts` + `/kp/*` — КП.

## Решения, принятые до дизайна

| Вопрос | Решение |
|---|---|
| Природа движка | Гибрид: код собирает доказательную базу и считает, формулировки и оси — человек |
| Масштаб | 10–30 сайтов, отобранных вручную |
| Источники данных | PageSpeed Insights API + Playwright. Wayback — **не берём** |
| Выбор осей разбора | Задаёт Василий под каждый сайт. Код их не предлагает |
| Экономическая модель | Переносится **как есть**, без изменений |
| Каркас КП | Извлекается общий каркас из broker/gagarin/bigsnt |
| Размещение | Всё внутри `aistov-space`, разбор — роут `/razbor/<domain>` |
| Стиль | Собственные scoped-токены, независимые от `@theme` |

### Следствие отказа от Wayback

Ось «возраст дизайна», которая в cooleso была третьей (дата последней
публикации, число версий в архиве), движком не обеспечивается. Если она
понадобится под конкретный сайт — данные придётся собрать руками или вернуть
Wayback в сборщик отдельным решением.

### Почему стили изолированы

Ссылка на разбор живёт месяц в чужом почтовом ящике. Фирменный стиль AICS-93
готовится к реворку. Если движок наследует токены `globals.css`, реворк молча
перекрасит разборы, уже отправленные и ещё не открытые. Поэтому обе ступени
получают замкнутый набор токенов в scoped-классах — по образцу существующего
исключения `.kp-doc`. Реворк бренда идёт своим темпом и не трогает то, что
в почте.

### Чего в движке нет и не будет

- **Сбор доменов из каталогов** (`collect.py` из исходного документа воронки) —
  домены отбирает Василий вручную.
- **Скоринг лидов A/B/C/D** — при 10–30 отобранных вручную сортировать нечего.
- **Рассылка, прогрев домена, четыре касания** — работа руками, автоматизация
  до проверки гипотезы строит непроверенное.

## 1 · Сборщик — `scripts/recon/`

**Запуск:** `npm run recon -- <domain>`
**Выход:** `data/recon/<domain>.json` и скриншоты в `public/razbor/<domain>/`.

### Источники

**PageSpeed Insights API** (ключ в `.env.local` как `PSI_API_KEY`), два вызова —
`strategy=mobile` и `strategy=desktop`:

- CrUX по реальным посетителям за 28 дней: LCP p75, INP p75, CLS, доля
  посетителей в пороге по каждой метрике, итоговый вердикт Core Web Vitals.
- Lighthouse: балл производительности, вес страницы, блокирующие рендер
  ресурсы, неиспользуемый JS и CSS, формат изображений.

**Playwright**, рендер в двух вьюпортах (1440 и 360):

- платформа по маркерам разметки: Tilda, Wix, Bitrix, WordPress, Readymag, Craftum;
- формы: количество и число полей в каждой;
- контакты: `tel:` и его кликабельность, `mailto:`, мессенджеры (wa.me, t.me,
  viber), ИНН по регулярному выражению, домен почты;
- счётчики аналитики: Яндекс.Метрика, Google Analytics, Top.Mail;
- HTTPS, наличие цен, CTA в пределах первого экрана;
- SEO-минимум: title, h1, description, Schema.org, sitemap.xml, robots.txt,
  собственная 404;
- горизонтальный скролл на 360px (`scrollWidth > clientWidth`);
- число страниц по sitemap.xml;
- два скриншота первого экрана.

### Контракт данных

Сборщик **не считает деньги и не выбирает оси**. Он записывает только
измеренное. Каждый источник несёт собственный статус:

```ts
type SourceStatus = "ok" | "unavailable" | "blocked";

type Recon = {
  domain: string;
  collectedAt: string;          // ISO
  psi:  { status: SourceStatus; mobile: PsiRun | null; desktop: PsiRun | null };
  page: { status: SourceStatus; data: PageFacts | null };
};
```

Недоступные данные — `null` при явном статусе, **никогда не ноль**. Ноль,
попавший в отчёт как «0 визитов», вскрывается за минуту на звонке и обнуляет
доверие ко всем остальным цифрам разбора.

Антибот (Cloudflare, Qrator, DDoS-Guard) → статус `blocked`, обход не
предпринимается. Между запросами — паузы; разбор десятков сайтов остаётся
вежливой операцией.

### Тесты

- Модуль детекта платформы и фактов страницы — юнит-тесты на сохранённых
  HTML-фикстурах (по одной на Tilda, WordPress, самописный).
- Разбор ответа PSI — на сохранённом JSON-ответе, включая случай отсутствия
  CrUX-данных у малопосещаемого сайта.
- Сквозной прогон на `cooleso.ru`: факты из JSON сверяются с тем, что
  утверждает существующий `public/kp/cooleso.html`.

## 2 · Экономический модуль — `src/lib/econ/`

Переносится без изменений из методики, применённой в cooleso:

- лифты не складываются: `lift = (∏(1 + lᵢ))^0.6 − 1`;
- потолок прироста конверсии +45%, потолок прироста органики +25%;
- коэффициент закрытия сделки — заявка не равна деньгам;
- коэффициент реализуемости по трём сценариям: 50 / 70 / 90%;
- окупаемость считается **по марже, не по выручке**.

Чистая функция без состояния:

```ts
model(input: {
  lifts: number[];
  traffic: number; conv: number; close: number;
  check: number; margin: number; price: number;
}): { conservative: Scenario; base: Scenario; optimistic: Scenario; payback: number };
```

### Тест пишется первым

На известных входах cooleso — 8000 визитов/мес, конверсия 2.50%, закрытие 25%,
чек 35 000 ₽, маржа 35%, цена 120 000 ₽ — модуль обязан выдать **354 682 ₽
прироста прибыли за год и окупаемость 4.1 месяца** в консервативном сценарии
и 977 398 ₽ в базовом. Расхождение означает, что модель воспроизведена неверно,
и это выясняется до первого письма, а не на созвоне.

## 3 · Разбор — роут `/razbor/<domain>`

### Контент-файл

`src/lib/razbor/<domain>.ts` — наполняет Василий, опираясь на JSON сборщика:

```ts
export const META = { domain, date, price, term, title, sub };

export const AXES: Axis[] = [ /* 2–4 оси */ ];
// Axis = { num, title, facts: string[], say: string }

export const ECON = { traffic, conv, close, check, margin, price, lifts };
export const EXTRAS: Block[] = [];   // опционально, как «обучение маркетологов» в cooleso
export const CTA = { title, text, button, href };
```

Оси задаёт человек. Их сила в том, что они подобраны под конкретный сайт:
cooleso технически исправен, поэтому там говорится про скорость, владение
и возраст, а не про отсутствие CTA. Скрипт так не умеет, а попытка научить
превращает разбор в чек-лист.

### Страница

Шапка → оси по порядку → блок денег → допблоки → CTA → методика.
`noindex, nofollow`. OG-картинка генерируется из домена.

**Блок денег — живой калькулятор.** Пять ползунков: визиты, конверсия,
закрытие, чек, маржа. Пересчёт мгновенный, на клиенте, через тот же
`src/lib/econ/`. В cooleso сейчас написано «укажите свои значения —
пересчитаем», то есть работа перекладывается на Василия и делается по
телефону. Ползунок делает это сам и попутно даёт сигнал намерения.

**Методика внизу страницы обязательна** — формулы, потолки, источники,
оговорка про оценку. Человек, который видит, как считали, верит цифрам
больше, а не меньше; а вопрос «откуда вы взяли эти цифры» — лучший сигнал
готовности покупать, и на него должен быть письменный ответ на той же странице.

## 4 · Каркас КП — `src/lib/kp/_skeleton`

### Что извлекается

Уже повторяется в broker/gagarin/bigsnt и переезжает в каркас:
`KpChapterNav`, `KpViewSwitch`, `KpCopyLink`, `RevenueBar`, квиз из `lib/quiz`.

### Набор секций со слотами

понимание задачи · что делаем и чего не делаем · цена и три схемы оплаты ·
гарантия · план по этапам · что нужно от вас · риски · FAQ · квиз

Секции опциональны и переставляются. Новое КП — один файл `src/lib/kp/<client>.ts`
и роут в три строки. Бесспоук-компонент добавляется только там, где клиенту
нужен собственный график.

Существующие четыре КП на каркас **не переписываются**: они сданы и работают.
Каркас извлекается из них и применяется к следующим.

### Связь ступеней

КП импортирует `src/lib/razbor/<domain>.ts`: те же оси и те же цифры, но уже
с фактическими данными, вытащенными на звонке. Человек не встречает в КП
других чисел, чем читал в разборе, — это первое, что он проверит.

### Содержательные константы каркаса

Из документа воронки, фиксируются в каркасе как значения по умолчанию:

- **Три схемы оплаты**: фикс со скидкой 10–15% · рассрочка 30/40/30 ·
  за результат (только при четырёх условиях, с потолком бонуса).
- **Гарантия, которую можно дать честно**: PageSpeed на мобильных ≥85,
  LCP ≤2.5 с, все дефекты из разбора закрыты, срок соблюдён. Конверсия
  не гарантируется никогда.
- **Границы срока**: «3 рабочих дня с момента, когда есть доступы
  и утверждённая структура», с перечнем оснований для паузы счётчика.
- **Что не входит**: новые смыслы и тексты, съёмка, брендинг, интеграции
  с 1С и CRM, личный кабинет, каталог свыше 200 позиций, мультиязычность,
  продвижение.

## 5 · Замер

Три события: **открыл разбор**, **тронул ползунки**, **нажал CTA**.

Уходят целями в Яндекс.Метрику и push-ом в Telegram. Второе важнее первого:
воронка требует звонить в тот же день, пока человек помнит, что читал.
Уведомление «cooleso.ru открыл разбор, подвигал ползунки» в момент события —
это и есть механика «звоним только по открывшим». Недельный отчёт её не даёт.
Telegram-канал уже обслуживает лиды с форм, подключаемся к нему.

Роут `/api/signal` принимает `{ domain, event }`, без персональных данных
и без хранения чего-либо о посетителе.

## Порядок сборки

1. Экономический модуль с тестом на цифрах cooleso — он проверяет, что модель
   воспроизведена верно, и от него зависят обе ступени.
2. Сборщик и контракт JSON, сквозной прогон на cooleso.ru.
3. Разбор: scoped-токены, каркас страницы, калькулятор.
4. Замер: `/api/signal`, цели Метрики, Telegram.
5. Каркас КП, извлечённый из существующих трёх.
6. Удаление разборов старше 30 дней — условие, объявленное в четвёртом письме,
   должно быть настоящим.

## Открытые вопросы

- **Ключ PSI API** — нужно завести в Google Cloud и положить в `.env.local`
  и в переменные окружения Vercel. Без него ось «скорость» недоступна.
- **Первый живой прогон** стоит просмотреть глазами на 5–10 доменах: детект
  платформы, вытяжка контактов и оценка веса страницы — места, где
  экстраполяция может завышать.
