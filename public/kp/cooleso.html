Обсудить расчёт

Методика. Влияние времени загрузки на конверсию — по данным Akamai (−7% на каждую секунду задержки). Влияние времени отклика (INP) — по данным Contentsquare на выборке 997 сайтов: мобильная конверсия 2.5% при хорошем INP против 2.0% при плохом; в расчёте использована меньшая величина. Эффекты не суммируются: перемножаются с демпфированием в степени 0.6, прирост конверсии ограничен 45%. Окупаемость считается по марже, а не по выручке. Применён коэффициент реализуемости 50 / 70 / 90% по трём сценариям. Показатели посещаемости, среднего чека и маржи — допущения по отрасли; при подстановке фактических данных расчёт меняется. Результат является оценкой и не может служить гарантией.
